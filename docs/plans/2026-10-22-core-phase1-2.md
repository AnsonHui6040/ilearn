# thu-ilearn 核心（Phase 1＋2）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 做出可在本機或 VPS 執行的 `ilearn` CLI：登入 iLearn、完整同步本學期資料及檔案到 SQLite／本地資料夾、判定完成狀態、按規則及時間產生事件寫入 outbox，並提供 agent 用的 CLI JSON 介面。

**Architecture:** 單一 TypeScript 核心。純邏輯（完成判定、規則、提醒、夜間、排程）與 I/O（HTTP、SQLite、檔案）分檔；純邏輯全部單元測試，I/O 以 Phase 0 結構寫成的 fixture 測試。CLI 只是外殼，所有判斷在核心。

**Tech Stack:** Node ≥ 22.13（本機 26.7）、TypeScript strict、ESM、`node:sqlite`（內建，不用原生模組）、vitest、eslint＋typescript-eslint、commander、@inquirer/prompts、yaml、ulid、tough-cookie、cheerio、@napi-rs/keyring。

**Spec:** `docs/design/2026-10-22-thu-ilearn-sync-design.md`；API 依據：`docs/verification/2026-10-22-phase0-api.md`

## Global Constraints

- 套件名 `thu-ilearn`，指令 `ilearn`，授權 MIT。
- 時區固定 `Asia/Taipei`；iLearn 時間為 UTC `Z` 字串，入庫存 ISO UTC，輸出事件用 `+08:00`。
- 資料根預設 `~/.thu-ilearn`，環境變數 `ILEARN_HOME` 覆寫；目錄 0700、檔案 0600。
- 密碼、cookie、token 不得寫入 log、事件、MD、CLI／MCP 輸出、錯誤訊息。
- 核心不呼叫 LLM。
- 只用 GET 讀 iLearn；登入 POST 是唯一例外。不改 iLearn 任何資料。
- 介面文字用台灣繁體中文（沒有、網路、檔案），不得出現廣東話用字。
- 事件 schema 字串 `thu-ilearn.event.v1`；`type` 只可用設計書「推送給 agent 的格式」的 15 個值。
- 提醒預設 `P1D`、`PT3H`；夜間 00:00–07:00；同步 07:00–24:00 每小時共 18 次＋03:30，每次 0–5 分鐘隨機延遲；提醒計時器每 5 分鐘。
- 子代理不准 commit 或 push；只可改自己任務列出的檔案。

## Review Focus

1. **網絡或 API 部分失敗**（某科 500、submission_list 逾時）→ 該科標「資料可能不完整」，推 `sync.incomplete`；已完成作業不可重開、未完成不可變完成、作業不可消失。Task 8 測試。
2. **`submitted=true` 但 `submission_list` 空**（Phase 0 實測出現）→ 保持未完成，附 `teammate_submitted_hint`。Task 4 測試。
3. **首次同步中斷再執行** → 已下載檔案不重下（hash 相同）、未完成的課程繼續；中途不得推送任何事件。Task 8 測試。
4. **跨夜邊界**：23:59 產生的 push 事件 `deliver_after` 為翌日 07:00；06:59 的 3 小時提醒即時；07:00 已有 3 小時提醒的事項不再送 1 日提醒。Task 6 測試。
5. **規則 YAML 寫錯**（未知 action、regex 無效）→ 載入失敗時拒絕儲存並顯示行數，執行中沿用上一份有效規則。Task 5 測試。
