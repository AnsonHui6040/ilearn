## 相關條文與本工具的做法

| 條文 | 內容 | 本工具 |
| --- | --- | --- |
| 使用辦法第六條第四款；帳號管理辦法第六條、第七條 | 不得無故將帳號借予他人使用 | 每位使用者在自己的電腦用自己的帳號登入；agent 不會取得密碼；不提供代管服務 |
| 使用辦法第六條第三款 | 不得盜用、冒用他人帳號 | 只能登入使用者自己輸入的帳號 |
| 使用辦法第六條第七款 | 不得掠奪資源、影響系統正常運作 | 每小時同步一次（另加 03:30），隨機延遲 0 到 5 分鐘；只用 GET，唯一的 POST 是登入 |
| 使用辦法第六條第九款；細則「嚴禁事項」第七款 | 不得從事非教學研究活動；不得傳送耗用大量頻寬的非教學資料 | 同步內容全部是使用者自己的課程資料與教材 |
| 細則「嚴禁事項」第三款 | 不得從事商業行為 | 免費、MIT 授權，不收集遙測 |
| 細則「嚴禁事項」第二款 | 不得使用可擷取「非經正式開放或授權之資訊」的軟硬體 | 只讀取使用者登入後本來就看得到的資料。**例外：`files.download_disallowed: download` 會嘗試下載老師關閉下載權限的檔案，與本款最接近** |
| 細則「嚴禁事項」最後一段 | 違規時暫停網路使用權，情節重大送學校議處 | README 聲明已提醒使用者自行查閱規範、自負責任 |

## 結論

1. 條文沒有明文禁止學生用自己的帳號以程式讀取自己的課程資料。
2. 風險最高的是「嘗試下載老師關閉下載權限的檔案」選項，建議公開發布前移除，或改為只在設定檔手動開啟並在 README 加上警告。需要使用者決定。
3. 同步頻率維持現狀，不要提高。
4. README 聲明保留。若要正式推廣給同學，建議先以電子郵件詢問電子計算機中心。
5. TronClass 服務條款未查到，仍是未確認項目。
