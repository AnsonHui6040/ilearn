# thu-ilearn Phase 4 終端機全螢幕介面 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增 `ilearn ui`：在互動終端開啟的全螢幕介面，分 5 頁（首頁、課程、提醒、課程設定、系統設定），以方向鍵、空白鍵、Enter 操作，給沒有 agent 的使用者查看資料及修改設定。

**Architecture:** 畫面全部由純函數產生：頁面函數把資料與狀態轉成「左右兩欄的行」，`renderFrame` 依終端欄數排版成字串陣列，`reduce` 處理按鍵並回傳狀態與副作用。只有 `app.ts` 接觸終端（raw mode、alternate screen、resize、每分鐘時鐘），需要文字輸入、Reload 或 `$EDITOR` 時暫時離開全螢幕，沿用 `@inquirer/prompts`。資料一律經既有查詢函式讀取，寫入集中在 `actions.ts`。

**Tech Stack:** Node ≥ 22.13、TypeScript strict、ESM、`node:readline`（keypress）、既有 `@inquirer/prompts`、vitest。不新增任何套件。

**Spec:** `docs/plans/2026-10-23-phase4-web-ui-audit.md` 第 9 節（已確認的分頁、按鍵、顯示規則、節次時間）；`docs/design/2026-10-22-thu-ilearn-sync-design.md` 第 5 版。

## Global Constraints

- 不新增 dependencies 或 devDependencies。
- `ilearn ui` 只能在互動終端執行：`stdin` 與 `stdout` 都是 TTY，否則 exit 1，訊息「介面需要在互動終端機執行」（沿用 `needTty`）。agent 無法經此介面寫入。
- 介面不提供修改 hook 指令、webhook 網址、帳號密碼、登入；只顯示狀態。
- 介面文字為台灣繁體中文，不得出現廣東話用字；底部按鍵說明中英並列，例如「Space 剔選 Select」。
- 按鍵：`1`–`5` 切換分頁；`←` `→` 切換左右欄；`↑` `↓` 移動；`PageUp` `PageDown` 捲一頁；`Space` 剔選；`Enter` 有剔選時進入確認畫面，沒有剔選時開啟該項；`Esc` 返回；`q` 離開；`Ctrl-C` 離開。
- 版面：100 欄與 80 欄為兩欄；80 欄以下改單欄（左欄在上、右欄在下，`←` `→` 切換焦點並捲到該欄）。任何一行的顯示寬度不得超過終端欄數。
- 中文、全形標點以兩格計算。
- 時間一律 Asia/Taipei（`src/time.ts`）。「當日」為本機系統時間今天 00:00 起。
- 首頁頂部顯示系統日期時間，格式 `2026-10-23（五）01:45`，每分鐘更新；與「最近同步 10-23 00:40」分開顯示。
- 課程代號：`code` 含 `_` 時取 `_` 之後，否則完整顯示，不截斷；教室欄寬依最長內容；課程名稱超過欄寬時換行，不截斷；公告為標題一行、課程名稱下一行。
- 未公布的分數不顯示（`score_published` 為 false 的列）。
- 子代理不准 commit 或 push；只可改自己任務列出的檔案。

## Review Focus

1. **標題含全形字、〈一〉（二）、emoji、長英文單字**：每一行寬度仍不超過欄數，截斷處以 `…` 結尾。Task 4 測試。
2. **使用中把視窗縮到 80 欄以下或極小（30 欄、8 行）**：改單欄，不崩潰；小於 40 欄或 10 行時只顯示「視窗太小，請放大 Window too small」。Task 4、Task 9 測試。
3. **`Ctrl-C`、例外或 `SIGTERM` 結束**：終端還原（離開 alternate screen、顯示游標、關閉 raw mode）。Task 9 測試。
4. **介面開著時 cron 同步改了資料，或規則檔被外部修改**：每次套用變更後及每分鐘重新讀取資料；套用前重新驗證（例如作業已變成完成就不再標記，規則檔無效就拒絕並顯示原因）。Task 8 測試。
5. **空狀態**：首次同步進行中、0 門課、沒有上課時間的課、今天沒有公告、課程所有區塊都空。不可顯示「沒有作業」來代替「首次同步進行中」。Task 5、Task 7 測試。
