# Phase 0：iLearn API 驗證紀錄

日期：2026-10-22。方法：使用者在 Claude browser pane 自行登入，之後以頁面內 `fetch`（只用 GET）讀取 API 結構。本檔只記錄欄位結構及統計，不記錄姓名、學號、cookie 或成績數值。

## 登入

| 項目 | 結果 |
| --- | --- |
| 入口 | `GET https://ilearn.thu.edu.tw/login` → 302 到 Keycloak CAS `https://tcidentity.thu.edu.tw/auth/realms/thu/protocol/cas/login?service=https://ilearn.thu.edu.tw/login&...` |
| 表單 | HTML `<form action="https://tcidentity.thu.edu.tw/auth/realms/thu/login-actions/authenticate?session_code=…&execution=…&client_id=tronclass&tab_id=…" method="post">`，欄位 `username`、`password`、按鈕 `login` |
| 驗證碼／雙重驗證 | 未見（頁面另有 TronClass App QR 登入，非必要） |
| 錯誤訊息 | 頁面有 `<input type="hidden" id="request_error_message" value="…">`；登入失敗時 Keycloak 會重新顯示同一表單 |
| 登入後 session | ilearn.thu.edu.tw 的 cookie `session`（另有 `_ga*` 分析 cookie，可忽略） |
| 登入確認 | `GET /api/profile` 回 200，`id` 為使用者 ID（數字） |

## 學期與課程

| API | 結構重點 |
| --- | --- |
| `GET /api/semesters` | `{semesters:[{id, name:"1151", is_active, academic_year_id, real_name, sort}]}`；`is_active=true` 的只有一個 |
| `GET /api/my-courses` | `{courses:[{id, name:"(1151_1236)數位行銷", course_code:"1151_1236", semester:{code:"115-1", id}, academic_year:{name:"115"}, start_date, end_date, study_completeness, instructors[], department}]}`，包括歷年課程（實測 74 門，115-1 有 12 門） |
| `GET /api/courses/{id}` | 另有 `course_outline:{status, external_url:"http://desc.ithu.tw/115/1/1236", common_fields:[{key,title,description}]×9}`、`classroom_schedule`（實測為 null） |
| `GET /api/todos` | `{todo_list:[{id, course_id, type:"homework", title, end_time(UTC Z), submit_rate, is_locked}]}`，只列未交作業，可作交叉核對 |

學期代碼換算：`semesters[].name` `"1151"` ↔ `courses[].semester.code` `"115-1"`。本學期課程 = `semester.code` 等於 active 學期換算值。

`course_outline.common_fields` 的 title：課程簡介、先修課程說明、課程概述、課程大綱、多元教學方式、基本教材、教學進度、評分方式、相關參考書目。實測 10 門課只有 1 門有填內容。

## 課程資訊連結（上課時間、教室）

- `external_url` 的 `desc.ithu.tw` 在瀏覽器顯示空白頁，curl 亦連不上。
- 可用來源：`https://course.thu.edu.tw/view/{學年}/{學期}/{課號}`，例如 `course_code "1151_1236"` → `/view/115/1/1236`。公開頁，不需登入。
- 頁面文字有「上課時間」欄，格式如 `三/2,3,4[M134]`（星期／節次[教室]），另有「授課教師」「評分方式」表格（項目、百分比）、「教育目標」「參考書目」。
- 每一堂資訊：此頁未見逐週表；以 iLearn `common_fields` 的「教學進度」為準（多數課程為空）。變更偵測以文字差異處理。
- 節次對應時間未驗證，需設定表。

## 活動（作業、教材、影片、問卷、會議）

`GET /api/courses/{id}/activities` → `{activities:[{id, type, title, start_time, end_time, deadline, published, completion_criterion_key, submit_by_group, group_set_id, uploads[], data{…}}]}`

本學期 12 門課的 `type` 統計：material 39、page 31、homework 25、online_video 4、microsoft_teams_meeting 2、forum 1、questionnaire 1。

## 作業及繳交紀錄

`GET /api/courses/{id}/homework-activities` → `{homework_activities:[{id, title, end_time, submit_by_group, submitted, submitted_status, user_submit_count, need_make_up, can_make_up_homework, make_up_closed_time, is_closed, score, score_published, …}], page, pages, total}`（有分頁欄位）

`GET /api/activities/{activityId}/students/{userId}/submission_list` → `{list:[{id, submitted_at, is_draft, is_redo, is_resubmitted, is_latest_version, marked_submitted, submit_by_instructor, created_by, group:{id, members[], group_users[]}, uploads:[{id, created_by_id, …}], score, final_score, instructor_comment, submission_correct:{comment, score}}]}`

實測重點：

| 情況 | `homework-activities` | `submission_list` | 判定 |
| --- | --- | --- | --- |
| 個人作業已交 | `submitted=true` | 1 筆，`created_by.id` = 自己 | 完成 |
| 小組作業，自己上傳 | `submitted=true` | 1 筆，`created_by=null`，`uploads[].created_by_id` = 自己 | 完成 |
| 小組作業，列表標記已交 | `submitted=true` | **0 筆** | 核實失敗 → 保持未完成，附註「系統顯示已交」 |
| `submitted_status="makeUp"` | `submitted=true` | 0 筆 | 同上 |
| 未交 | `submitted=false` | 0 筆 | 未完成 |

結論：`submitted` 旗標不可作完成依據，必須以 `submission_list` 有非草稿紀錄為準；小組作業以 `created_by.id` 或任一 `uploads[].created_by_id` 等於自己判定「自己有繳交紀錄」。`need_make_up` 語意不明（未交、未截止的作業亦見 `true`），不作退回依據。

## 影片進度

`GET /api/course/{id}/activity-reads-for-user` → `{activity_reads:[{activity_id, activity_type:"learning_activity"|"exam_activity", completeness:"full"|"part", data:{actions:["submit"]}, last_visited_at}]}`

只有 `full`／`part`，沒有百分比。`online_video` 以 `completeness="full"` 視為 100%。未觀看的影片沒有紀錄。

## 考試／測驗

`GET /api/courses/{id}/exams` → `{exams:[{id, title, start_time, end_time, is_started, is_closed, submit_times, exam_submissions[], score_percentage, …}]}`（本學期共 2 個）

`GET /api/courses/{id}/exam-scores` → `{exam_scores:[{activity_id, score, submission_scores[]}]}`

## 公告

`GET /api/courses/{id}/bulletins` → `{bulletins:[{id, title, content(HTML), created_at, updated_at, start_time, end_time, created_by, uploads[]}]}`（本學期共 15 則）。`/api/course/{id}/bulletins`、`/announcements` 均為 404。

## 檔案

- 上傳物件欄位：`{id, reference_id, name, type:"document"|…, size, allow_download, link, key}`；出現在活動 `uploads`、公告 `uploads`、繳交紀錄 `uploads`。
- 下載：`GET /api/uploads/{id}/blob` → 302 到 `tcmedia.thu.edu.tw`，實測回 `application/pdf`。
- `GET /api/uploads/reference/document/{reference_id}/url?preview=true` → `{status, url}`（預覽網址）。
- `allow_download=false`：本學期 67 個上傳物件中有 17 個，即老師關閉下載。blob 端點仍可取得檔案，處理方式待決定。
- `link` 不為 null 時屬外部連結，只記錄網址。
