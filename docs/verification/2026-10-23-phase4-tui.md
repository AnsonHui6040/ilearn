# Phase 4（終端機全螢幕介面）驗收紀錄

日期：2026-10-23。分支：`claude/phase4-web-ui-f1b5e4`，由 `main`（`b4d874a`，PR #2 合併後）開出。設計依據：`docs/plans/2026-10-23-phase4-web-ui-audit.md` 第 9 節、`docs/design/2026-10-22-thu-ilearn-sync-design.md` 第 5 版。實作計劃：`docs/plans/2026-10-23-phase4-tui.md`。

## 已確認決定

| 項目 | 決定 |
| --- | --- |
| 形式 | 不做網頁，改為 `ilearn ui` 終端機全螢幕介面，給沒有 agent 的使用者使用 |
| 分頁 | 1 首頁（需要處理）、2 課程、3 提醒、4 課程設定、5 系統設定 |
| 按鍵 | 1 到 5 切換分頁；方向鍵移動或切換左右欄；空白鍵剔選；Enter 確認或開啟；Esc 返回；q 離開 |
| 寫入 | 剔選後先顯示「將變更 N 項」，再按 Enter 才寫入；只能在互動終端開啟 |
| 設定 | 系統設定可改通知規則（啟用、關鍵詞、新增、試算）、推送方式、介面、夜間時段、截止提醒、帳號（重新登入、登出），另有 Reload、立即同步、Reset；設計書 Stage 7 只剩設定精靈最後的確認畫面 |
| 節次時間 | 依使用者提供的 115-1 東海課表，預設寫入 `period_times` |
| 公告日期 | iLearn 發布時間 `created_at`；「提醒」頁只列當日及之後 |
| 窄終端 | 80 欄以下改單欄；40 欄或 10 行以下顯示「視窗太小，請放大」 |

## 禁用字掃描

對本 Phase 新增或修改的 `.md` 與 `src/tui/*.ts` 掃描廣東話用字、簡體字、中間點分隔符、emoji 與裝飾性箭嘴。結果：沒有命中（「關係」為一般用字）。按鍵說明中的方向鍵符號（上下左右）屬於按鍵名稱，不是裝飾。
